# Documentation Practice
This repository is for practicing documentation changes using GitHub's website.
## How to Contribute
1. Open 'README.md' and make your changes.
2. Select the Preview tab to check how the Markdown will appear.
3. Check your changes for formatting problems and broken links.
4. Commit your changes to your working branch.
5. Open a pull request that explains what you changed and why.
## Before You Start
Make sure your changes are clear and easy to understand.
